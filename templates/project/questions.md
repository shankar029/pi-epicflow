# Project Memory — Open Questions

> Unresolved questions the project is tracking but hasn't decided.
> Each question has a stable id (`Q-NNN`), an owner, and a
> "resolves when" trigger. When a question is answered, the answer
> goes to `decisions.md` as a `DEC-NNN` entry with `resolves: Q-NNN`,
> and the question's status flips to `resolved`.
>
> Append-only for new questions. The single non-append edit permitted
> is flipping `**Status:** open` → `**Status:** resolved (see DEC-NNN)`
> when the answer lands.

**Last verified:** {{DATE}}
**Cap:** 50 open + 200 resolved; open entries > 1 year → archive to
`questions-archive-<YYYY>.md` (see SKILL.md "Capacity & rollover").
